# Roz Ka Nizam

Roz ka time-wise schedule, discipline tracker aur reminders. Mobile par app ki tarah install hoti hai.

## Files (sab seedhe repo ke root mein hon, kisi folder ke andar nahi)
- index.html (poori app)
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png (install ke liye)
- vercel.json (settings)

## GitHub par upload
1. github.com par New repository banao (naam: roz-ka-nizam).
2. "uploading an existing file" par click karo.
3. Zip khol kar andar ki sab files drag karo, Commit changes dabao.

## Vercel par live
1. vercel.com par GitHub se login karo.
2. Add New, Project, apni repo Import karo.
3. Framework Preset: Other. Build Command aur Output Directory khali chhor do.
4. Deploy dabao. 1 minute mein link mil jayega.

## Phone mein install
- App mein "App install karo" ka button hamesha nazar aata hai (upar aur neeche). Browser ne prompt diya to seedha install, warna button saaf qadam dikha deta hai.
- Android (Chrome): menu ⋮ mein "Install app" ya "Add to Home screen". WhatsApp ya Instagram ke andar link na kholo, Chrome mein kholo.
- iPhone (Safari): Share dabao, "Add to Home Screen".

## Reminders
- "Reminder on karo" dabao aur Allow karo. Ye tab kaam karta hai jab app khula ya background mein ho.
- App band hone par bhi pakka alert chahiye to "Calendar mein daalo" dabao. File kholo aur calendar mein add karo, phone roz alarm bajayega.
